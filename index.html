ONE TIME SETUP

Connect Dropbox, then choose one folder for your music library.

Flurb requests read-only access and stays inside your selected folder.
  1. Flurb uses a Full Dropbox app type so it can reach your existing music folder, with only files.metadata.read and files.content.read enabled.
  2. Flurb’s browser UI selects one library folder, then lists and plays tracks only inside that folder and its subfolders.
  3. Add https://joecorsi.github.io/flurb-web/ under OAuth 2 → Redirect URIs. The app key is already filled in.

For local development, run python3 -m http.server 8080 from the web folder and use http://localhost:8080/ as the redirect URI.
